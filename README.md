# Kenyan Holiday Explorer

A simple Single Page Application that shows public holidays in Kenya using a public API.


## Features

- Fetches holiday data from a public API
- Filter holidays by month
- Switch between light and dark mode
- Responsive design

## Tech Used

- HTML
- CSS
- JavaScript
- Public API [nager.at Public Holidays API](https://date.nager.at)

## How to Use

1. Clone this repo or download ZIP
2. Open `index.html` in your browser
3. Click "Show Holidays"
4. Use the dropdown to filter by month
5. Toggle dark mode if you want!
